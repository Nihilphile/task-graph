# 导出列表为 CSV

## 目标与范围

在已有列表页面提供导出入口，生成包含当前结果全部行的 UTF-8 CSV。此切片打通读取列表数据、生成文件与触发下载的完整路径；筛选条件联动由后续任务补齐。

## 输入与约束

沿用列表已有的列名和列顺序；读取数据时遵守现有访问权限。列值中的逗号、双引号和换行按 CSV 规则转义。复用项目现有下载和验证入口。

## 完成条件与验证

- 从实际列表入口能下载 CSV，行列与当前无筛选结果一致。
- 中文、逗号、双引号、换行能被重新解析成原值。
- 空列表导出只有表头，失败时展示可理解的反馈。
- 记录使用的验证方法、结果与尚未覆盖的边界；不把未运行检查写成通过。

## 交付

提交实现与必要检查，把验证结果写到 `doc/reports/csv-export/base.md`，通过 task complete 的 --report 参数绑定到本任务。
