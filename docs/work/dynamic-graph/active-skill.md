## 要求

作为与 to-task 互斥的规划工作流：建骨架、细化前沿、评估实际能力/信息缺口、适量新增调查/决策/实现依赖、组织独立验收。主控已授权范围内自行协调，需用户裁决才提问。多份 content 增量添加，不复制前置 reference。可显式注册自己的 Desktop UUID watch。
