# 手动审查重新开启验收门槛，保留已发生的后继工作

主控可以在阅读完成报告后才确定 RR 并启动手动审查，因此被审查任务可能已是 done，后继也可能已经开始。决定将该任务转为 pending_review，阻塞尚未开始的完整依赖；已有后继继续执行，reject 时向主控报告影响，由主控安排处理。只附报告而保留 done 会让尚未验收的结果继续满足依赖，自动回滚后继则可能破坏已经发生的独立工作，因此采用此边界。

局部完成点继续由指定子任务的完成状态决定，父任务的审查不额外封锁已满足的局部能力。需要局部验收时，对相应子任务启用审查；需要整体验收时，依赖父任务。
