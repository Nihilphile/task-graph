# 独立审查的判断原则

审查对象是当前轮次固定的交付与要求。逐项验证 RR 和明确任务约束，报告实际证据与覆盖范围；额外风格或重构建议单列。

| 结论 | 依据 |
| --- | --- |
| pass | 验收条件有相应证据支持 |
| reject | 发现违反验收约定的事实，附证据与失败复盘 |
| blocked | 环境、输入、判据或现场状态不足，无法形成可靠结论 |

审查中保持被审源码原样，修复由后续任务执行。用本轮 review-id 交卷，成功回执才算完成；聊天结语和进程退出不能代替交卷。具体材料读取、报告和命令见 [审查交卷](../operations/review-submit.md)。
